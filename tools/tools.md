# Tools

Tools need:

- `tools/deploy.py`: ssh, rsync, python3-yaml and the section `deploy` of `secrets.yaml`
- `tools/loc-stats.py` (code statistics in README.md): cloc (Debian package cloc)
- Browser test (`tools/test/`): Node 20 and Chrome
- Demo (`tools/demo/`, see [demo.md](demo/demo.md)): backend packages; screenshots: Node 20, Chrome, ffmpeg
- Serial test helpers: pyserial (in the PlatformIO `fw/.venv`)
