{% if project_rows %}

Each row shows the pipelines of one project, one LED per pipeline: GitLab: the main pipeline of each ref. GitHub: each workflow of each branch. The stages and jobs in a pipeline have no LED. LED 1 has the oldest pipeline, the next LEDs have newer ones, the rest of the row is off. A pipeline moves to the new end when a new run starts. The row has {{ row_len }} LEDs: if there are more pipelines, the oldest are not shown.

Max. age: a pipeline without change for this time is not shown. Empty: the default (grey text), 0: no limit. Values: seconds or e.g. 12h, 7d. Colour and light as for one job: PASS green, FAIL red, WARN yellow, UNKNOWN white; waits: fast pulse, runs: slow pulse.

{% else %}

Each LED shows one job: select the source, then the things in it, from coarse to fine. For GitLab: project, ref (branch or tag), then a job of the main pipeline or a trigger job (its downstream pipeline), then a job of the downstream pipeline. "(this pipeline)" stops there: the LED shows the main pipeline (at the ref) or the downstream pipeline (at the trigger job). For GitHub: repository, branch, workflow, then a job of the workflow. "(this workflow)" stops at the workflow: the LED shows its newest run. For generic jobs (scripts): the names that the script set. The lists have the jobs that sent events. "(off)" means the LED is off. The name is optional, a short label for the device display.

Max. age: when the last change of the job is older, its data is outdated: the LED shows no data (status and result UNKNOWN, info "outdated"). This also covers a final event that never comes. Values: seconds or e.g. 1h, 1d12h, 7d. Empty (or 0): forever.

Sounds: the device plays a melody (or on the Hello the sound effect) when the job stops. Fail: result FAIL or WARN, pass: result PASS, each time. Pass → fail: FAIL or WARN after PASS, fail → pass: PASS after FAIL or WARN; these two play instead of fail and pass, if set. The lists have the sounds that the device reports (needs a newer firmware). If more jobs stop at the same time, the device plays one sound: pass → fail first, then fail, fail → pass, pass; the lowest LED first. ▶︎ plays the selected sound on the device now, also before you save.

Colour: result of the last run: PASS green, FAIL red, WARN yellow, UNKNOWN (or no result yet) white. Waits: fast pulse, runs: slow pulse, no data: blink.
